# App Store screenshot set

These 1206 × 2622 screenshots were captured on an iPhone 17 Pro simulator using Tali's isolated
`-tali-demo` in-memory store. They contain deterministic sample data and no personal records.

1. `01-dashboard.png` — recent entry, activity chart, and neutral sample activities
2. `02-habit-detail.png` — elapsed time, activity chart, and timestamp history
3. `03-fast-logging.png` — habit, editable timestamp, and optional note
4. `04-elapsed-time-controls.png` — per-habit elapsed-time visibility
5. `05-export-controls.png` — global elapsed-time setting plus CSV and JSON exports

Re-capture this set whenever the release UI changes. Confirm the accepted screenshot dimensions in
App Store Connect before uploading; never stretch these files to satisfy a different slot.
